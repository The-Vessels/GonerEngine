# GONERENGINE

GonerEngine is a [DELTARUNE](https://deltarune.com) fangame engine built on top of the [Godot](https://godotengine.org) game engine, trying to be as accurate to the original game as possible. We are currently still early in development and usage of the engine for your fangame is not recommended.
Though you are more than welcome to look around and possibly contribute too.

## Important Links

Our [documentation](https://thevessels.github.io/gonerengine-docs) has a complete API reference of all classes in Godot,
as well as articles detailing the design of this engine.
If you want to contribute to this documentation, check its
[GitHub repository](https://github.com/TheVessels/gonerengine-docs).

Be sure to join our [Discord Server](https://discord.gg/2Ea2bpQGq5) for the latest news and updates about "GonerEngine"!
